# 数据指标分析平台

面向指标口径定义、多维度聚合分析、AB实验评估、数据服务发布与数据应用交付的数据指标分析平台。

这是一个前后端分离的管理平台：前端 React + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 React + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 数据血缘 × 数据建模联动

血缘关系与模型定义是打通的：血缘端点可以绑定模型字段，模型字段变更会被生效血缘约束。

- **草稿与生效快照**：血缘关系先落草稿（新增/修订/停用/整组替换），`POST /api/lineage/publish`
  把当前整组关系作为一个结果校验并固化为快照。自环、跨多条关系形成的环、缺失模型字段
  都会让整组失败，失败时旧快照继续生效；批内顺序不影响判断。
- **并发裁决**：发布携带 `base_snapshot_version` 与 `base_model_versions`，模型字段变更
  携带 `base_version`，只接受基于当前生效版本的修改，冲突响应里写明双方各自依据的版本；
  模型删除/改名被生效快照引用的字段会被整组拒绝，避免产生看似有效却指向不存在字段的图。
- **影响分析**：`POST /api/lineage/impact` 从模型字段出发沿字段链展开，区分直接、间接与
  多路径重复影响；结论可保存，保存时冻结当时的快照版本与路径，之后图变了历史结论仍按
  当时版本展示。停用关系并发布后，新分析自动采用新图。
- **历史自由文本兼容**：未绑定模型的旧关系以「自由文本」标记共存、按节点名精确串联，
  不参与字段级影响分析，无法解析的旧关系明确标出，绝不伪造到模型的连接。
- **操作闭环**：血缘页「发布中心」发布失败 → 冲突「图上定位」→ 「修订」关系 → 重新发布 →
  「影响分析」选定模型字段展开影响路径 → 点「查看模型」跳到模型定义页查看受影响字段；
  模型页删字段被拦时会给出引用它的关系清单，可跳回血缘页处理。

验证脚本（覆盖菱形依赖、环路、模型删字段、版本裁决、历史结论回溯等 55 项检查）：

```bash
cd backend && ./run.sh &          # 先起后端
.venv/bin/python tests/verify_lineage.py
```
